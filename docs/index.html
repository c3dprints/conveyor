Pi Poop Conveyor

Runs a Bambu Lab purge ("poop") conveyor belt from a Raspberry Pi 4. The Pi watches your printers on your home network and runs the belt when they need it, with touchscreen controls and a web page for setup.

What it does

  • Runs the belt every few minutes while printing, after a filament change (AMS purge), and when a print ends.
  • Works with Bambu Lab printers over local MQTT (X1, P1 and A1 series), with network discovery.
  • The 5 V USB gear motor plugs straight into the Pi: no ESP32 or MOSFET board.
  • Touchscreen controls for a 5" HDMI or 4.3" DSI screen, plus a web page at http://conveyor.local.
  • Updates itself from GitHub when you press Install.

Quick install

On a Raspberry Pi 4 running Raspberry Pi OS (64-bit, desktop):

git clone https://github.com/c3dprints/conveyor.git ~/poop-conveyor-pi
cd ~/poop-conveyor-pi
sudo bash install.sh
sudo reboot

Then open http://conveyor.local/setup to add your printers. The guide covers every step.

Based on the MakerWorld "WiFi smart poop conveyor" (model 2594649).
